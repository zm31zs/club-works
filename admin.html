登录（连接你的 GitHub 仓库）

令牌是什么、怎么拿？
  1. 打开 GitHub → 右上角头像 → Settings → 最底部 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Token name 随便填（如“作品展后台”），Expiration 选 90 天
  3. Repository access 选 Only select repositories，只勾选你的作品展仓库
  4. Permissions → Repository permissions → Contents 选 Read and write
  5. 生成后复制那串字符，粘贴到上方输入框即可
令牌只保存在你当前浏览器，不会写入网站代码，也不会出现在前台页面。
修改后必须点「保存并发布」才会写入仓库并生效；约 30–60 秒后刷新前台可见。删除操作可通过 Git 历史恢复。
